# AI Studio 使用说明（非程序员版）

你不需要懂 GitHub、TypeScript、React，也不需要学习复杂 Prompt。

## 平时怎么做

1. 一直使用同一个 AI Studio 项目继续对话开发。
2. 直接用你自己的业务语言说你想实现什么，不需要说文件名或函数名。
3. 较大的修改开始前，先建立一个 Checkpoint。
4. 修改完成后，自己在页面上实际操作一遍，确认结果符合你的想法。
5. 然后对 AI Studio 说下面这句话：

> 检查刚才的修改，只检查我要求的功能，不要增加新功能。运行 TypeScript 检查和生产构建。最后用简单中文告诉我：完成了什么、修改了哪些文件、有没有影响其他功能、检查是否通过、我现在需要手动测试什么。

6. 如果修改后程序明显不对，不要连续让 AI 反复修很多轮。优先使用 Restore 回到上一个正常 Checkpoint，再重新描述需求。

## 不要做什么

- 不要频繁重新从 GitHub Import。
- 不要自己添加 `AGENTS.md`、`GEMINI.md` 或其他大型规则文件。
- 不要为了一个小问题要求 AI “全面重构整个项目”。
- 不要在功能已经坏掉的状态下连续叠加很多修复。

## 版本原则

日常开发使用 `aistudio-dev`。

`main` 是稳定版本，不作为日常试验区。

如果 AI Studio 出现严重问题，由技术维护者负责从 GitHub 恢复；日常使用者不需要自己处理分支、合并或回滚。
